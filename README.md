# Library Management API

## Project Description

This project is a RESTful API for managing a library system using Node.js, Express, Sequelize, and SQLite.

It allows users to manage:

- Authors
- Books
- Relationships between authors and books

Each author can have multiple books, and each book belongs to one author.

---

## Technologies Used

- Node.js
- Express.js
- Sequelize ORM
- SQLite
- Postman
- GitHub
